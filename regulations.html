一 · 定价与精算规定核心

保监发〔2015〕19号 2015-02-13
中国保监会关于万能型人身保险费率政策改革有关事项的通知
  • 万能型精算规定的现行基础文件（最低保证利率由公司审慎确定）
  • 被保险人年满18周岁的，保单签发时死亡风险保额不低于保单账户价值的 20%
  • 单独账户管理，同一账户的保单采用同一结算利率
  • 责任准备金 = 账户准备金 + 最低保证利率准备金 + 其他保单利益准备金
  • 后续叠加：万能评估利率上限经保监发〔2016〕76号调整为年复利3%；金规〔2025〕14号实施全面从严的万能新规
🔗 原文：监管总局官网（docId=359811）
保监发〔2015〕93号 2015-09-28
中国保监会关于推进分红型人身保险费率政策改革有关事项的通知
  • 分红型精算规定的现行基础文件：预定利率由公司审慎确定（高于3.5%报审批，不高于报备案）
  • 利益演示低/中/高三档利差水平分别不得高于 0、4.5%−预定利率、6%−预定利率（93号原文口径）口径变更 一年期以上分红险演示口径已被 银保监规〔2022〕24号改为「保证利益演示 + 红利利益演示」两档，利差水平 ≤ 0 / 4.5%−产品预定利率（取消中、高三档及 6%−预定利率档）
  • 个人分红终身寿险、个人分红两全保险死亡保险金额不低于已交保费的 120%
  • 未到期责任准备金评估利率 = min（定价利率, 3.0%）
  • 注意：红利演示现受银保监办发〔2020〕6号红利上限公式实质约束，见本页 6号卡片

银保监办发〔2020〕6号 核心 2020-01-21（2020-02-21发布）
中国银保监会办公厅关于强化人身保险精算监管有关事项的通知
  • 责任准备金覆盖率：引入该指标并纳入非现场监测，与产品监管措施挂钩；报送条款费率审批/备案的，最近季度末覆盖率不得低于 100%。
  • 分红利益演示红利上限：用于分红险利益演示的红利不得超过 (V₀ + P) × 利差水平 × 红利分配比例（统一 70%）。V₀ 为本保单年度期初红利计算基础对应的准备金（不含生存给付金），P 为本保单年度净保费；「利差水平」即利益演示用的利差假设。口径变更 演示档数已被 银保监规〔2022〕24号由低/中/高三档改为「保证利益演示 + 红利利益演示」两档，利差水平分别 ≤ 0 / 4.5%−产品预定利率（取消原中、高三档及 6%−预定利率档）——红利上限公式的两档利差即取此值。

金发〔2024〕18号 核心 2024-08-02
国家金融监督管理总局关于健全人身保险产品定价机制的通知

中国银保监会关于印发一年期以上人身保险产品信息披露规则的通知
  • 一年期以上产品说明书与利益演示的细化规则（2022年第8号令的操作层），全链条信息披露要求
  • 分红实现率披露制度：现金红利实现率 / 增额红利实现率的计算与官网年度披露；实现率计算以 4.5% − 产品预定利率 为利益演示基础
  • 分红型演示执行口径（本站重点）：演示保单利益应当采用 保证利益演示 和 红利利益演示 两档，取消原 93 号文低 / 中 / 高三档表述。用于利益演示的 利差水平分别不得高于 0、4.5% − 产品预定利率——即保证利益演示（低档）利差 = 0，红利利益演示（高档）利差 ≤ 4.5% − 产品预定利率。保险期间 ≤ 10 年逐年演示各保单年度末利益；期间 > 10 年演示前 10 年各保单年度末利益；并须醒目标明「基于公司精算及其他假设、红利分配不确定」，不得披露演示用投资回报率。
  • 万能型两档演示（最低保证利益演示 + 万能结息利益演示；低档 = 最低保证利率、高档假设结算利率 ≤ 4%）
