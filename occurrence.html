📊 发生率选择三表详解 · 官方原表数据

定价发生率是三参数中最不该拍脑袋的一个。本页基于官方发布原表（生命表2025四类表 CL1–CL4、重疾表2020 全系 CI1–CI10 + K1–K3 + MI、意外表2021）逐岁数据绘图，支持单条查看、多条叠加、任意组合对比——选错表是产品报备与回溯环节的高频驳回原因。

1四类表全量对比 · 分年龄死亡率 qx（0–105 岁逐岁官方原表值）
中精协发〔2025〕80号附件四张表的完整逐岁 qx（单位 1/1000）。切换性别、点击图例即可单看一张表、多表叠加或任意组合对比。三张经验表形态相近但水平分层清晰；非养老一表（CL2）最高（身故责任为主，安全边际上调）、养老类表（CL1）最低（生存责任为主，死亡率下调）、单一生命体表（CL4）居中不加边际。

四类表 qx 曲线（log 刻度） 👆 点击图例可显示 / 隐藏任一条曲线

数据来源：《中国人身保险业经验生命表（2025）》附件四张表（CL1 养老类业务表 / CL2 非养老类业务一表 / CL3 非养老类业务二表 / CL4 单一生命体表，男女分列，单位 ‰，0–105 岁共 106 点）。纵轴 log₁₀(qx‰)：每 +1 格，死亡率 ×10；105 岁 = 1000‰ = 100% 为终龄假设。
对数刻度怎么看
y = log₁₀( qx ‰ )　→　刻度 3 / 2 / 1 / 0 / −1 对应死亡率 100% / 10% / 1% / 0.1% / 0.01%
原始刻度下，青壮年（<1‰）与高龄段（>50‰）相差两个数量级，低龄段会被压成贴地直线；取对数后整条曲线舒展开。举例：CL2 男性 40 岁 qx = 1.202‰ → log₁₀ ≈ 0.08；CL1 男性 80 岁 qx = 52.78‰ → log₁₀ ≈ 1.72。
2四类表 · 男女死亡率差异（男 ÷ 女比值，按官方原表逐岁计算）
用 CL1–CL3 官方原表逐岁计算男性 qx ÷ 女性 qx：三张风险分类表形态一致——0 岁新生儿差异小（1.26 左右），35–40 岁达到峰值（≈2.7 倍），随后缩窄，100 岁左右趋平。这是「女性死亡率总体低于男性、预期寿命更长」的直接量化，也是男女差别费率的数据根源。

男/女死亡率比值 官方原表计算

比值 = 同表同龄男性 qx ÷ 女性 qx，据中精协发〔2025〕80号附件原表逐岁计算（每 5 岁抽样展示）。非养老一表（CL2）中青年段比值最高（身故责任敏感），养老类表（CL1）高龄段比值略低。

4编表方法（中精协发〔2025〕80号官方口径）
要素口径
观察期2014-01-01 至 2021-12-31（8 年）
粗发生率数据基于 2018-01-01 至 2021-12-31 经验数据计算，反映平均时点（2019-12-31）死亡率水平
趋势调整附加 5 年趋势因子，将死亡率水平从平均观察时点调整到编表完成时点（2024-12-31）；趋势因子主要依据观察期（2014–2021）经验数据拟定，并结合人口数据调整
四表构成经验生命表 3 张（CL1 / CL2 / CL3）+ 单一生命体表 1 张（CL4），每张均分男 / 女表，0–105 岁
预期寿命
第四套生命表保险人群预期寿命男 81.1 岁 / 女 85.4 岁，较第一套分别 +10.2 / +10.3 岁；全年龄年均死亡率下降 3.9%。
少儿改善最快
少儿段死亡率年均下降 7.6%（较全年龄高 3.7 个百分点）；6–7 岁学龄儿童死亡率最低，之后随年龄上升。
趋势因子（21岁+）
行业首次按自身经验设定：养老类 男 0.5% / 女 1.0%，非养老一 男 1.5% / 女 2.0% —— 每年向下修正身故率。
分红盈余计算基础
金规〔2025〕21号第五条：分红产品盈余与红利计算以第四套生命表为基础；存量分红产品可用原表或第四套，但须确保计算公平、保护保单持有人权益。
偏离度与回溯
金规21号第六条：厘定费率与评估准备金时须列明偏离度评估区间；建立可检视、可计量的回溯机制，背离区间须在年度精算报告详细说明原因并经董事会审议通过。
主体责任
金规21号第七条：未基于精算原理审慎选表、未及时回溯调整、定价风险长期未改善的，监管部门将依法采取监管措施并追究公司及相关责任人员责任。

提前给付型重疾 + 死亡责任的评估下限公式（51号文原文）
重疾责任发生率 + 死亡责任发生率 ≥ ix + qx − kx × qx
ix = 对应 CI 表发生率；kx = 对应 K 表比例；qx 为经验生命表非养老类业务一表死亡率（51号文发布时为 2010–2013 版；2026-01-01 起按金规〔2025〕21号应改用第四套生命表 CL2）。若重疾责任保额高于死亡责任保额，重疾责任超出部分以 ix 为评估下限。
来源：银保监发〔2020〕51号（中国政府网）第三条。适用范围：包含重大疾病保险责任的长期人身保险产品；2007-08-01 前备案产品承保病种至少含恶性肿瘤、急性心肌梗塞、脑中风后遗症 3 种，之后备案的至少再含重大器官移植等共 6 种。
定义先行
发生率表建立在《重大疾病保险的疾病定义使用规范（2020 修订版）》（中保协发〔2020〕73 号）28 重度 + 3 轻度统一定义之上；条款病种拆分、增删不得违反规范。
甲状腺癌降级效应
TNM 分期 T1N0M0 及更轻的甲状腺癌划入轻度后，2020 版定义「严重恶性肿瘤」发生率下降、轻度发生率上升——新旧定义产品发生率不可直接套用。
评估下限
法定责任准备金评估使用重疾发生率不得低于重疾表2020对应水平（ix 下限 + K 值按 51号文规则）；定价可以更保守，但不能低于评估底线。
中青年女性更高
28 病发生率中青年段女性高于男性（乳腺、甲状腺等），约 50 岁后男性反超并逐步拉开——男女性别费率差异的根源。
心梗性别差最大
CI8 心梗发生率中青年男性约为女性的 10 倍以上（35 岁 0.287‰ vs 0.026‰），是所有病种中性别差异最悬殊的——含心梗单病种责任的产品性别费率必须拉开。
65 岁上下切换
评估下限规则中「65 岁以上是否包含阿尔茨海默+帕金森」直接决定 ≤65 岁与 >65 岁分别用 6 病种表还是 25/28 病种表——病种清单须逐款核对，这也是 CI10 参考表存在的意义。

一 · 生命表2025：四类表怎么选

四类表 核心
CL1 养老类 / CL2 非养老一 / CL3 非养老二 / CL4 单一生命体
  • 养老类业务表 CL1：以生存保障责任为主的两全保险、年金保险（年金领取期定价的核心表，死亡率改善即长寿风险的直接来源）
  • 非养老类业务一表 CL2：健康险、以死亡保障责任为主的定期寿险和终身寿险
  • 非养老类业务二表 CL3：生存和死亡保障责任兼具的其他终身寿险、两全保险和年金保险
  • 单一生命体表 CL4：被保险人个体死亡发生率经验——研究用途，可借此持续提升定价科学性（金规21号第四条）
选表要点 易错
同一产品多责任 ≠ 多张表随便用
  • 按主要责任定基准表：年金险身故责任可以谨慎加成，但不能因身故责任把年金产品整体切到非养老一表
  • 分红险盈余与红利计算以第四套生命表为基础；存量分红产品切换表须确保计算公平、保护保单持有人权益（金规〔2025〕21号第五条）
  • 定价须结合第四套生命表和自身经验数据、按审慎性原则确定（第二条）；评估与定价均须列明偏离度评估区间（第六条）
  • 生命表2025较2010-2013表死亡率显著改善——老产品直接换表重算会出现责任准备金跳变，切换方案要留痕

二 · 重疾表2020：CI 系列 + K 系列 + MI

系列内容用途
CI 系列（10 张）CI1–CI2（2007 版定义）、CI3–CI4（2020 版定义定价基准）、CI5–CI6（大湾区专属参考）、CI7–CI9（恶性肿瘤/心梗/脑中风专项）、CI10（阿尔茨海默+帕金森参考表）重疾险定价的基础发生率来源；专项表做单病种分析与病种拆分参考
K 系列（3 张）K1（适用 CI1/CI3/CI5）、K2（适用 CI2/CI4/CI6）、K3（适用 CI7）——因重大疾病死亡占全部死亡的比例重疾险死亡责任拆分、法定评估下限必用（银保监发〔2020〕51号第三条规则）
MI 参考表3 轻度疾病与 28 重度疾病发生率比例（分年龄段、分性别）轻度疾病发生率参考——可在行业表基础上按公司经验调整，依据写入精算报告
  • 病种定义先行：发生率表建立在《重大疾病保险的疾病定义使用规范（2020年修订版）》（中保协发〔2020〕73号）28种重度+3种轻度统一定义之上——条款病种拆分、增删不得违反规范，规范外病种定义须明确无歧义。
  • 轻度疾病：轻度疾病发生率可在行业表基础上按公司经验调整，但调整依据须写入精算报告。
  • 评估下限：法定责任准备金评估使用重疾发生率不得低于重疾表2020对应水平（ix 下限 + K 值按 51号文六情形规则），定价可以更保守但不能低于评估底线。

三 · 意外表2021：意外险定价的全国基准

  • 表结构：按性别 × 年龄的意外身故、意外伤残（分伤残等级）发生率——首次将意外险定价从「各公司自估」拉到行业统一基准。
  • 职业系数：意外表2021配合职业类别系数使用（职业分类参照中国保险行业协会职业分类目录）；涉高职业须在费率或承保规则中体现。
  • 费率浮动：银保监办发〔2021〕106号允许按职业、渠道等维度费率浮动，但浮动规则须在备案材料中说明。
  • 定价回溯：意外险赔付率、发生率偏离须分析说明（106号文明确要求）——定价时建议在行业表基础上预留经验调整与回溯空间，不要贴表定价。
  • 伤残评定：伤残给付须符合行业统一伤残评定标准（现行：GB/T 44893—2024）。

五 · 实操注意：发生率不是选完表就完事

加成与边际 定价自由度
行业表是基准，不是天花板
  • 定价可在行业表基础上向上加成（保守边际），加成逻辑须可解释、可回溯
  • 向下突破行业表（比行业更乐观）= 报备高风险点：需充分经验数据支撑，且不得低于法定评估下限（重疾 ix+K 值下限、意外表2021回溯约束）
  • 目标客群若与全国人口结构差异大（如次标体、特定职业），发生率假设的适配上移是驳回高发点
假设管理闭环 2026新规
设定 → 验证 → 回溯（金办便函〔2026〕616号 + 金规〔2025〕21号第六条）
  • 发生率假设纳入统一精算假设管理体系：与实际经验定期对比、修正
  • 金规21号：死亡发生率偏离度评估须列明区间；回溯发现背离区间 → 年度精算报告详细说明 + 董事会审议通过
  • 上市后回溯：意外险（106号）、互联网产品（1275号）、产品年度总结报告（360号）三处都会暴露发生率偏差
