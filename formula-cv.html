现金价值公式 + 计算实战

最低现金价值不是公司随意定的，由法定系数表锁死下限——防止早期退保损害保单持有人利益。

核心制度：银保监办发〔2020〕7号《普通型人身保险精算规定》第九条（保单年度末保单价值准备金的计算基础与利率）、第十条（保单年度末保单最低现金价值）；保监发〔2015〕93号《分红保险精算规定》第九条、第十条（分红型口径）。万能型见保监发〔2015〕19号《万能保险精算规定》。

一、公式与变量定义

最低系数
　r = k% + t × (100% − k%) / min(20, n)　（当 t < min(20, n) 时）
当 t ≥ min(20, n) 时，r = 100%。
保单年度末保单最低现金价值
　MCV = r × Max(PVR, 0)　（PVR = 保单年度末保单价值准备金，按法定基础算得；其计算用利率＝预定利率 + 法定加点，见第二节）
险种 / 缴费方式系数 k（%）
个人两全保险 / 个人年金保险（期交）90
个人终身寿险（期交）80
团体两全 / 团体年金（期交）95
团体终身 / 团体定期（期交）85
趸交（任意险种）100

t = 保单年度（1 起算）；n = 缴费期间（年）。min(20, n) 表示系数在 20 个保单年度内线性爬升至 100%，之后恒为 100%。

二、现金价值计算用利率（预定利率的选取）

MCV 的基数 PVR（保单年度末保单价值准备金）不是按定价利率算的，而是按法定加点后的利率算：

险种保险期间现金价值计算用利率
分红型10年及以下预定利率 + 1.0%（示例：1.75% → 2.75%）
分红型10年以上预定利率 + 1.5%（示例：1.75% → 3.25%）
传统型（普通型）一年以上险种报备时厘定保险费所使用的预定利率 + 2%（示例：2.0% → 4.0%）
万能型—不适用本表：按保单账户价值 − 退保费用确定

依据：分红型——保监发〔2015〕93号《分红保险精算规定》第九条；传统型——银保监办发〔2020〕7号《普通型人身保险精算规定》第九条；万能型——保监发〔2015〕19号。示例按现行预定利率上限试算，实际以本产品报备利率为准。

PVR 的三项法定计算基础：①发生率＝报备时厘定保险费所用预定发生率；②附加费用率＝法定表定数值（非公司实际费用）；③利率＝上表。计算方法：按各保单年度净保费（按 PVR 基础重新计算的毛保费 ×(1−法定费用率)）用未来法计算，不包括该保单年度末的生存给付金额。

易错点：定价预定利率 ≠ 现金价值计算用利率。前者受上限约束（见预定利率专页），后者＝前者 + 法定加点，加点不是定价利率，不可用于定价。详见导航仪面板5「现金价值计量设计」与保险产品精算AI助手（初期利率已按本表自动带出）。

三、计算实战

最低现金价值演算器

选择险种设定 k，输入保单年度、缴费期间、单位准备金

实战举例

个人年金（期交，k=90），缴费期 n=20，第 t=5 保单年度，单位准备金 1,000。
min(20,20)=20；r = 90% + 5×(10%)/20 = 90% + 2.5% = 92.5%。
最低现金价值 MCV = 92.5% × 1,000 = 925。公司实际现金价值不得低于此下限。

四、深度说明

  • 为什么设下限：早期退保时公司已经发生获取费用（佣金、核保、系统），若允许过低现金价值，退保客户承担全部费用损失、留存客户被摊薄——76号文以法定系数强制保护。
  • 与准备金的关系：最低现金价值以准备金为计提基础，本质是「不使退保金低于法定准备金对应部分」，保证偿付能力不被早期退保侵蚀。
  • 公司现价 vs 法定下限：公司可直接以 MCV 作为保单年度末现金价值，也可按其他合理基础与方法确定，但不得低于 MCV，且须在精算报告中明确体现该比较（负面清单第62条）；采用增额红利分配方式的，还需计算每单位增额红利现金价值。
  • 短期险另成一套：保险期间一年及以内的产品，保单年度中保单最低现金价值不得低于未经过净保费（7号文第十三条；负面清单第63条）。
  • 系数随年度爬升：前 20 年系数线性上升，意味着早期退保惩罚递减、后期趋近 100%，对应获取费用的分摊回收节奏。
