📋 产品开发需求及评估报告通用指导

产品开发流程的第二环：需求从哪里来、报告必须写什么、七个部门各评什么、九类风险怎么识别——本页是《产品开发需求及评估报告》的通用指导，围绕所选产品与定价结构逐节落位：形态参数、定价三参数、毛保费、现金价值、利益演示与四视角数据（映射表见第八节，写作顺序见第九节，提交前自检见第十节）。

如何使用本指导： 适用于已完成具体产品定价的阶段——报告从「骨架」进入「填数」：形态参数、定价三参数、毛保费、现金价值、利益演示与四视角数据围绕这款产品的定价结构逐节落位（映射表见第八节，写作顺序见第九节，提交前自检见第十节）。
定价实验室完成后 · 围绕所选产品与定价结构完成报告

在定价实验室跑出具体产品的形态参数、定价三参数、毛保费、现金价值表、利益演示与四视角数据之后，报告从骨架进入填数：每一处数值都要能回溯到定价结果的某个输出项——形态抄第一区、结构讲三参数、保费用 GP、卖点指向演示表、盈利结论引用管理层视角。三节依次给出映射表、写作顺序、提交前自检清单。

八 · 定价结果 → 评估报告映射表

定价实验室的每一项输出，在报告里都有明确的落位。填数阶段按这张表逐行搬运，禁止脱离定价结果另编数值：

定价实验室输出填入报告栏目填写要点
产品类型 / 保险期间 / 交费期间 h（第一区） 形态描述 与条款表述逐字一致；保险期间与交费期间的口径（保至 N 岁 / 保 N 年、交至 N 岁 / 交 N 年）要写成条款语言，不写工具内部代号。
发生率表及系数、表版本（第一区自动带出） 形态描述 · 定价结构 写明所选生命表 / 重疾表、版本年份与调整系数（如 ×70%）——发生率口径是产品比较与回溯评估的共同基准。
定价三参数：预定利率 i、发生率 qx、费用率 et 定价结构说明 逐参数写依据：预定利率对照监管上限与预定利率专页档位；费用率对标报行合一法定上限；三参数共同支撑「充足性、适当性、公平性」结论。
毛保费 GP / 千元保额费率（定价结果汇总） 市场分析 · 件均保费；产品比较 · 保费 件均保费 = GP × 投保份数；与竞品对表统一用千元保额比（GP ÷ 保额 × 1000），避免保额口径不同导致的伪优劣。
现金价值表（逐保单年度 CV） 产品比较；市场分析 现价前低后高的走势与回本年度是客户视角核心信息；报告需写明现价计算利率口径（分红型 / 普通型加点规则）并确认表内数值 ≥ 法定最低现金价值。
利益演示表（产品利益演示区） 市场分析 · 产品卖点分析 每个卖点必须能在演示表里指到具体保单年度的具体金额——「讲得出数字」的卖点才能进报告；分红型按两档口径，红利不确定提示同步写明。
四视角透视（销售 / 客户视角） 市场分析 · 卖点（客户、业务员两视角） 客户视角的 IRR / 回本 / 满期收益直接支撑「客户为什么买」；销售视角的佣金与件均支撑「业务员为什么卖」——报告卖点分析两栏的数据源。
四视角透视（管理层 / 精算视角） 重大保险风险测试评估；盈利性结论 管理层视角的利润测试口径（定价口径示意）直接支撑「新业务价值大于零、内含价值率不低于最低可接受水平」的结论表述。
一表贯穿：报告、精算报告、产品说明书、宣传培训材料用的都是同一套定价输出——任何一个环节改数，全链条同步重跑，杜绝「报告一个数、说明书一个数」。

九 · 围绕定价结构的报告写作顺序

完成定价后，推荐按以下顺序把数据落进报告（先锁形态，再讲结构，最后填市场与风险）：

步动作围绕产品与定价结构怎么做
1锁形态从定价实验室第一区抄录产品类型、保险期间、交费期间、发生率表（含版本与系数）→ 填入「形态描述」；同步核对投保及搭配规则与定价时的一致性。
2讲结构写「定价结构」小节：预定利率、发生率、费用率三参数取值与依据 + 毛保费求解结果（GP、千元保额比）——让评审一眼看懂「这产品贵不贵、为什么这么贵」。
3反推销售量用 GP 定件均保费 → 按渠道销售计划拆件数 → 给出上线后 3 个月、6 个月、1 年、2 年、3 年保费规模期望值及简单测算过程（GP × 件数，过程留痕）。
4同口径比产品「产品比较」用千元保额比与竞品同口径对比（平台 / 渠道 / 地区各三款以上）；比较维度里保费、现价两列直接取定价输出，其余维度补市场信息。
5填卖点「市场分析 · 产品卖点分析」按客户 / 业务员两视角填：客户视角引用利益演示与 IRR / 回本年度；业务员视角引用件均保费与佣金建议——每条卖点标注数据出处年度。
6过风险九类风险逐条对照本产品定价结构：保险风险写发生率表与退保假设、市场风险写预定利率与投资收益假设的匹配、费用风险写费用率对标报行合一——风险描述落到参数，不写空话。
7下结论盈利性结论引用管理层视角数据：新业务价值大于零、内含价值率不低于最低可接受水平；与审批链要求的「充足性、适当性、公平性」逐项对应。

十 · 提交前自检清单（围绕定价数据）

报告提交会签前，逐项打勾——任何一项不过，先回定价实验室核对，不带病上会：

✓自检项
□报告中的费率、现价、演示数据与定价实验室输出逐项一致，无手工另编数值。
□千元保额比可复算：GP ÷ 基本保额 × 1000，报告值与定价结果误差为零。
□现价表覆盖每个保单年度，且 ≥ 法定最低现金价值（口径按产品类型写明）。
□分红型产品红利两档演示，红利不确定提示在正文出现（非仅脚注）。
□销售量预测与 GP 反推过程留痕：3 个月 / 6 个月 / 1 年 / 2 年 / 3 年期望值均有简单测算过程。
□产品比较 ≥ 3 款同口径（平台 / 渠道 / 地区各三款以上），保费列统一千元保额比。
□定价三参数均有依据出处：预定利率档位、发生率表版本与系数、费用率对标报行合一上限。
□盈利性结论有数据支撑：新业务价值 > 0、内含价值率 ≥ 最低可接受水平（管理层视角口径）。
□与现有产品关系已评估：是否冲击在售主力产品及应对措施写明（防止左手打右手）。
通过标准：全清单通过后，报告随评估意见、立项计划表一并走总精算师 → 总经理审批链（见第七节）——审批通过的形态与参数即锁定，后续进入产品上线和上市 →。
