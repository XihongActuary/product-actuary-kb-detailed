定价实验室

年金保险、两全保险（分红型／普通型）、重大疾病保险——产品精算报告口径的公式法定价全流程工作台。

产品形态 → 自动发生率表 → 保险责任参数 → 毛保费求解；逐保单年度展开换算函数、年度给付、现金价值、法定准备金（分红型另含红利利益演示）。

定价完成后，可按管理层／销售／客户／精算四种视角一键透视并单页导出。

各参数口径与注释已统一移至第七区块「公式与口径说明」开头之「参数口径与注释」表格，页面内不再散落说明文字。

定价方程（公式法，迭代求解）
GPx = [ Σt=1..T (DBx+t·Cx+t−1 + SBx+t·Dx+t) + GPx·h·Dx+T ] / Σt=1..h [ Dx+t−1·(1−et) ]
换算函数
Dx=1；Dx+t=Dx+t−1·v·(1−qx+t−1)；Cx+t−1=v1/2·Dx+t−1·qx+t−1；v=(1+i)−1
身故保险金
DBx+t = Max( GPx·Min(t,h), tCVx )　（年末现金价值与累计已交保费取大）
生存给付
SBx+t = 0（t<关爱周年日）；BSA×比例（t=关爱周年日）；GPx·Min(t,h)×年金比例（t≥年金起始周年日）
现金价值（双口径）
初期/终极：PVRb(t) = [Σk=t+1..T(DB·C + SB·D) + 满期·DT]/Dt − Σk=t+1..h[GP′b·(1−e′k)·Dk−1]/Dt；CVb(t) = rt·Max(PVRb(t), 0)
rt = k + (1−k)·t/Min(20,h)（t<Min(20,h)），否则 1；k=1（趸交）/ 0.9（期交）
保单年度末保单最低现金价值 MCV（法定下限）
PVR（保单年度末保单价值准备金）：为计算最低现金价值而按法定基础算得的准备金（不含该保单年度末的生存给付）——发生率＝报备时厘定保险费所用预定发生率；费用率＝法定表定值；利率＝报备时厘定保险费所使用的预定利率 + 2%（银保监办发〔2020〕7号《普通型人身保险精算规定》第九条，即本页「初期」口径）
MCV = rt × Max(PVR, 0)：本工具输出的年末 CV 即按此式计算（n＝交费期间 h，趸交 n=1；k：期交 0.9／趸交 1）。公司可按其他合理基础确定现价，但不得低于 MCV，且须在精算报告中体现该比较（负面清单第62条）；保单年度中现价按年末现价合理确定（第十二／十三条） 年度融合：tCV = CV₁（t≤1）；CV₁×(4−t)/3 + CV₂×(t−1)/3（1<t<4）；CV₂（t≥4）
法定未到期责任准备金（一年期完全修正法 FPT）
均衡净保费 PNL、首年净保费 α、续年净保费 β；tV = Max(tV* + tVd, tCV)，其中 tVd 为保费不足准备金 = Max(β−GP, 0)×未来净保费年金现值
年中现金价值
年中CV = 0.5 ×（年末CV + 年初CV + 年中生存给付 + 现价净保费 GP′·(1−e′t)）

为什么必须迭代：生存年金、满期金、身故金均是「累计已交保费」（= GP×Min(t,h)）的函数，而现金价值又依赖 GP′ 与身故金——GP 同时出现在定价方程两侧，报告因此注明「利用精算模型迭代计算出」。本工具采用不动点迭代（自适应阻尼），并在结果区显示迭代轮数与残差。

口径来源：预定利息率与发生率；附加费用率（银保监办发〔2020〕7号上限内）；现金价值双口径与融合规则；FPT准备金与保费不足准备金。生命表2025四类表逐岁数据见发生率专页。

符号：x 投保年龄；h 交费期间；T = 满期年龄 − x 保险期间（默认 105 − x，满期年龄可输入其他周岁或切换「保N年」）；et 定价附加费用率；e′t 现价基础附加费用率；GP′ 按现价计算基础（i+2% 或定价利率 + e′）计算的毛保费；BSA 基本保险金额。

定价方程（两全分红型，公式法，迭代求解）
GPx = [ Σt=1..h DBx+t·Cx+t−1 + BSAx·Dx+T ] / Σt=1..h [ (1−et)·Dx+t−1 ]　（满期金 = 基本保额×给付比例，为定价锚）
身故或全残保险金 DB（含180日规则与给付比例系数R）
t=1：DB = 0.5×Max(GP×R, 1CV) + 0.5×GP；t>1：DB = Max(GP·Min(t,h)·R, tCV)
R 分龄系数：18–40周岁 r₁（默认160%）/ 41–60周岁 r₂（默认140%）/ 61周岁及以上 r₃（默认120%）；18周岁以下不乘系数；在计算系数时，到达年龄 = 投保年龄 + 保单年度 − 1（保单年度初年龄，与 qx+t−1 同龄；本工具按此口径，与按保单年度末年龄 ≤41/≤61 划界公式数值等价）
现金价值（双口径）
初期口径 3.25%（=定价利率+1.5%，93号文：保险期间>10年）/ 终极口径 1.75%；现价净保费 = GP′×(1−et)（报告F042，用定价费用率）
CVb(t) = rt·Max(PVRb(t), 0)；rt 同年金口径；年度融合：tCV = CV₁（t≤1）；CV₁×(3−t)/2 + CV₂×(t−1)/2（1<t<3）；CV₂（t≥3）
保单年度末保单最低现金价值 MCV（法定下限）
PVR（保单年度末保单价值准备金）：按法定基础算得的准备金（不含该保单年度末的生存给付）——发生率＝报备时厘定保险费所用预定发生率；费用率＝法定表定值（分红型见表7）；利率＝预定利率 + 1.0%（保险期间10年及以下）/ + 1.5%（10年以上）（保监发〔2015〕93号《分红保险精算规定》第九条，本页「初期」口径随保险期间自动切换）
MCV = rt × Max(PVR, 0)：本工具输出的年末 CV 即按此式计算（n＝交费期间 h；k：期交个人 0.9／趸交 1）。公司实际现价不得低于 MCV（负面清单第62条）；采用增额红利的，另需计算每单位增额红利现金价值（第十一条）
法定未到期责任准备金（修正法，非FPT）
评估利息率 = Min(定价利率, 1.75%)；α = Max(DB₁·Cx/Dx, PNL − 3.5%×DB₁)（分红险特有下限）；β = (PNL·ΣD − α·Dx) / Σt=2..hDx+t−1；tV = Max(tV′ + tVd, tCV)
红利利益演示（利差红）
周年红利 = b×Max((t−1V + 当年净保费)×(i*−i), 0)；i* 演示利率（默认3.50%）、b 可分配比例（默认70%）
当年净保费：第1年 α、续年（2≤t≤h）β、缴费期后 0（报告F079统一记β，本工具按 α/β/0 实现并注明）
交清增额：按每千元保额独立链在评估基础上反向递推；红利演算至满期前一年（满期年度合同终止）
年中现金价值
t=1：年中CV = 0.5×(年末CV + 现价净保费)；t>1：年中CV = 0.5×(年末CV + 年初CV + 现价净保费)

为什么必须迭代：身故或全残金是「累计已交保费×R 与现金价值取大」，现金价值又依赖 GP′ 与身故金——GP 同时出现在定价方程两侧。本工具采用活动集线性求解 + 不动点迭代（自适应阻尼），结果区显示迭代轮数与残差。

口径来源：预定利息率 1.75% 与发生率（金规〔2025〕21号选表）；附加费用率（原保监发〔2015〕93号上限内，分红型）；现金价值双口径与融合规则（93号保险期间>10年档）；修正法准备金；红利演示与交清增额。生命表2025四类表逐岁数据见发生率专页。

符号：x 投保年龄；h 交费期间；T=满期年龄−x 保险期间；et 定价附加费用率；e′t 现价基础附加费用率（分红版 5年交 30/20/15/12/12%）；GP′ 按现价计算基础计算的毛保费；BSA 基本保险金额；bt 报告记法的满期年龄。

定价方程（中短期两全·分红型，公式法，迭代求解）
GPx = [ Σt=1..bt DBx+t·Cx+t−1 + BSAx·Dx+bt ] / Σt=1..pt [ (1−et)·Dx+t−1 ]　（满期金 = 基本保险金额，为定价锚；bt=5/6/8/10，pt=1/3/5）
身故保险金 DB（无180日等待期规则，按报告F029）
x+t ≤ 18：DB = Max(GP·Min(t,pt), tCV)　（18周岁及以下不乘给付比例系数）
18 < x+t：DB = Max(GP·Min(t,pt)·R, tCV)
R 给付比例系数：18<x+t≤41 → 1.6；41<x+t≤61 → 1.4；61<x+t → 1.2（报告F030；等价于条款口径「18–40周岁 160%/41–60周岁 140%/61周岁及以上 120%，在计算系数时到达年龄 = 投保年龄 + 保单年度 − 1」）
现金价值（单口径，预定利息率 2.75%，93 号文保险期间 10 年以上档）
